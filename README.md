# IELTS Academy Homepage

## Live Demo

Visit the live application: [IELTS Academy Homepage](https://github.com/P-FardeenMalik/IELTS)

## Features

### Core Sections
- **Navigation Bar**: Fixed header with responsive mobile menu
- **Hero Section**: Compelling headline with CTA buttons and success statistics
- **Features**: 4 key service offerings with detailed descriptions
- **Testimonials**: Student success stories with ratings and achievements
- **Footer**: Complete contact information and navigation links

### Technical Features
- **Fully Responsive Design**: Optimized for mobile, tablet, and desktop
- **Modern React Architecture**: Functional components with hooks
- **CSS-in-JS Styling**: Inline styles for better component encapsulation
- **Interactive Elements**: Hover effects and smooth transitions
- **Performance Optimized**: Fast loading with Vite build system
- **Cross-browser Compatible**: Works on all modern browsers

## Technology Stack

- **Frontend**: React 19.1.1
- **Build Tool**: Vite 7.1.7
- **Styling**: CSS-in-JS (Inline Styles)
- **Package Manager**: npm
- **Version Control**: Git

## Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/P-FardeenMalik/IELTS.git
   cd IELTS
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

5. **Preview production build**
   ```bash
   npm run preview
   ```
